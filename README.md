**Утга илэрхийлдэг өнгө хэвээр**: ногоон (хэвийн), шар (анхаарал), улбар

### Алтлаг өргөлт

Цэнхэр нэг гэр бүлээр бүрдсэн тул нэг **тод өргөлт** хэрэгтэй болсон. Хөх + алт нь
албан ёсны сонгодог хослол бөгөөд сайтын тэмдэгт аль хэдийн байсан. Алтлагийг
хоёр хувьсагчаар салгасан:

| Хувьсагч | Утга | Хэрэглээ |
|---|---|---|
| `--gold` | `#e0a526` (бараанд `#e8b84d`) | **Зөвхөн дүүргэлт, зураас** |
| `--gold-ink` | `#8a6b1f` (бараанд `#d6ad55`) | Бичвэр |

Яагаад салгасан бэ: тод алтлаг цагаан дээр бичвэр болоход эсрэгцэл **2.2** буюу
уншигдахгүй. Зураас, дүүргэлт болгоход харин маш тод (хөх дээр 4.4).

Хаана харагдана: самбарын гарчгийн өмнөх тэмдэглэгээ, тоон хайрцгийн зүүн ирмэг,
идэвхтэй цэсний мөрийн зураас, хэсгийн дэд гарчгийн зураас, зургийн туузны доод
ирмэг, гарын авлагын хаалттай хэсгийн тэмдэг.

> Алтлаг нь **чимэглэлийн бүтэц** бөгөөд төлөв илэрхийлэхгүй. Анхааруулгын шар
> (`--warn`) нь үргэлж цэгтэй чип буюу тайлбарын талбай хэлбэртэй байдаг тул
> хоорондоо эндүүрэхгүй.

Өнгө нь зөвхөн өргөлт биш, **гадаргуу дээр ч** ажиллана: хуудасны дэвсгэр,
зүүн цэс, толгойн мөр, самбарын толгой цэнхэр өнгөтэй; хүснэгтийн толгойн мөр
цайвар цэнхэр дэвсгэртэй; идэвхтэй цэсний мөр үндсэн өнгөөр дүүрнэ. Хүснэгтийн
нүд өөрөө цагаан хэвээр — тоо унших нь нэн тэргүүнд.

Бичвэрийн эсрэгцлийг хоёр загварт хэмжиж тохируулсан — бүх хослол
**WCAG AA (4.5:1)**-аас дээш:

| | Цайвар | Бараан |
|---|---|---|
| Үндсэн бичвэр | 16.8 | 11.9 |
| Хоёрдогч | 8.9 | 6.9 |
| Бүдэг (хамгийн муу гадаргуу дээр) | 4.9 | 4.9 |
| Хүснэгтийн толгой | 9.8 | 7.6 |
| Идэвхтэй цэс | 9.7 | 5.8 |
| Холбоос | 4.8 | 6.2 |

Бараан загварт үндсэн өнгө цайвар болдог тул түүн дээрх бичвэр цагаан байж
болохгүй. Иймд `--on-accent` хувьсагч нэмсэн: цайвар загварт цагаан, бараанд
бараан. Хүснэгтийн толгойн бичвэр `--accent-ink`-ээр — хоёр загварт хангалттай
эсрэгцэлтэй.

### Дэвсгэр зураг

Сансраас харсан агаарын тээврийн сүлжээний зураг (`assets/bg-earth.jpg`, 341KB)
нь **агуулгын ард биш, тусгаарласан туузанд** хэрэглэгдэнэ. Албан ёсны цахим
хуудасны жишиг ийм байдаг: өгөгдөл агуулсан хэсэг тайван, нэг өнгийн дэвсгэртэй,
зураг нь тодорхой хүрээтэй баннерт байрлана.

| Хаана | Хэлбэр |
|---|---|
| Нүүр хуудас | Бүтэн өргөнтэй **баннер тууз** — гарчиг, товч тайлбар, үзүүлэлтүүд |
| Хяналтын сан | Зүүн цэсний **толгойн тууз** (байгууллагын нэр) |
| Гарын авлага | **Нэвтрэх дэлгэцийн** дэвсгэр |
| Өгөгдлийн хэсэг | Зураггүй — цэвэр гадаргуу, дүүрэн өнгөтэй самбар |

Тууз бүр `.photoband` ангиар ажиллана (`assets/theme.css`): зураг дээр
байгууллагын хөх өнгийн хөшиг тавьж, доод ирмэгт нь алтан зураас нэмнэ.
Хөшиг нь зүүн талдаа 95%, баруун талдаа 54% тул **гарчиг талдаа бичвэр бүрэн
тодорч**, нөгөө талдаа зураг харагдана. Бичвэрийн эсрэгцлийг хэмжсэн: гарчиг
16.9, догол мөр 13.3, шошго 9.9 — WCAG AA-гийн шаардлагаас өндөр.

> ⚠️ Туузан дээрх бичвэрийн өнгийг зааж буй дүрмүүд нь `.hero p`, `.brand .mark`
> зэрэг **үндсэн дүрмүүдийн дараа** байх ёстой. Өмнө нь тавибал загварын хуучин
> бараан өнгө нь дарж, бичвэр уншигдахгүй болно (энэ алдаа хөгжүүлэлтийн явцад
> хоёр удаа гарсан).

Зургийн замыг `--page-photo` хувьсагчаар зааж, **үнэмлэхүй** (`/assets/…`)
бичсэн: CSS хувьсагч доторх харьцангуй зам нь загварын файл биш,
**хуудасны хаягаар** шийдэгддэг.

```
public/                 ← нийтлэгдэх агуулга (build output directory)
  index.html
  hyanalt/{index.html, config.js, db.js}
  hyanalt/intl-snapshot.json  ← ICAO-гийн үзүүлэлтийн нөөц хуулбар
  garyn-avlaga/index.html
  assets/theme.css      ← гурван хуудсын нэгдсэн албан ёсны загвар
  assets/bg-earth.jpg   ← гурван хуудсын дэвсгэр зураг
  assets/gate.js        ← гарын авлагын нэвтрэлтийн хаалт
  _headers              ← Cloudflare Pages-ийн аюулгүй байдлын толгойнууд
functions/api/intl.js   ← ICAO iSTARS прокси (Cloudflare Pages Function)
supabase/schema.sql     ← хүснэгт, эрхийн дүрэм, эх өгөгдөл
test/                   ← локал тест (нийтлэгдэхгүй)
serve.js                ← локал сервер (нийтлэгдэхгүй)
```

## 1. Supabase — өгөгдлийн сан

1. [supabase.com](https://supabase.com) дээр үнэгүй бүртгүүлж **шинэ төсөл** үүсгэнэ.
   Бүс нутгийг **Singapore** эсвэл **Tokyo** сонговол Монголоос хамгийн хурдан.
2. Зүүн цэснээс **SQL Editor** → **New query** → `supabase/schema.sql`-ын
   **бүх агуулгыг** хуулж тавиад **Run**.
   Энэ нь 9 хүснэгт, эрхийн дүрэм, 2026 оны I хагас жилийн эх өгөгдлийг үүсгэнэ.
   Дахин ажиллуулахад аюулгүй — давхардсан бичлэг үүсгэхгүй.
3. **Authentication → Users → Add user** дээр админ хэрэглэгч үүсгэнэ
   (и-мэйл + нууц үг). *Auto Confirm User* -ийг заавал асаана.
   Зөвхөн энэ хэрэглэгч өгөгдөл нэмэх, засах, устгах эрхтэй.
4. **Authentication → Providers → Email** хэсэгт
   **«Enable email signups»**-ийг **УНТРААНА**. Ингэснээр гаднаас хэн ч
   өөрөө бүртгүүлж бичих эрх авахгүй.
5. **Project Settings → API** хуудаснаас хоёр утгыг хуулна:
   - **Project URL** (`https://xxxx.supabase.co`)
   - **anon / publishable key** (`eyJ...` эхэлдэг урт түлхүүр)
6. `public/hyanalt/config.js` файлыг нээж тэр хоёр утгыг тавина.

> ⚠️ **`service_role` түлхүүрийг ХЭЗЭЭ Ч энд тавьж болохгүй.** Тэр нь эрхийн
> дүрмийг тойрдог. `anon` түлхүүр нь нийтэд ил байхаар зориулагдсан бөгөөд
> аюулгүй — хамгаалалтыг RLS дүрэм хангана (хүн бүр УНШИНА, зөвхөн
> нэвтэрсэн хэрэглэгч БИЧНЭ).

## 2. Cloudflare Pages — нийтлэх

**GitHub-аар (зөвлөж байна — дараа нь push хийхэд автоматаар шинэчлэгдэнэ):**

1. GitHub репозитор: **https://github.com/jagaajacky99/MNG** — үүсгэж, түлхсэн. ✅
2. Дахин холбох шаардлагатай бол (remote аль хэдийн тохируулагдсан):
   ```bash
   git remote add origin https://github.com/jagaajacky99/MNG.git
   git push -u origin main
   ```
3. [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** →
   **Create** → **Pages** → **Connect to Git** → репозитороо сонгоно.
4. Тохиргоо:
   - **Framework preset:** `None`
   - **Build command:** хоосон орхино
   - **Build output directory:** `public`
5. **Save and Deploy.** Төсөл `mrt-mn`, домайн `mrt-mn.pages.dev` — үүсгэсэн. ✅

**GitHub-гүйгээр (хурдан турших):** Pages → **Upload assets** дээр
`public` хавтасны агуулгыг чирж оруулна.

### Домайн нэр

(Settings → General → Project name). Өөрийн домайнтай бол
Custom domains хэсгээс үнэгүй холбоно.

## 3. Шалгах

Нийтлэгдсэний дараа:

- `/hyanalt/` нээхэд баруун дээд буланд **«Зөвхөн харах»** гэж гарвал
  сан зөв холбогдсон.

  өөрчлөгдөж, хүснэгт бүрт **Засах** ба **+ … нэмэх** товч гарч ирнэ.

- **«Сангийн холбоо алга»** гэвэл URL/түлхүүр буруу, эсвэл `schema.sql`
  ажиллаагүй байна. Хөтчийн консолоос алдааг харна.

## 3.1. Зочны харагдацыг тохируулах

Зөвхөн нэвтэрсэн админд. **Тохиргоо → Зочны харагдац** хэсэгт гурван бүлэг жагсаалт:

| Бүлэг | Юу удирдах вэ |
|---|---|
| **Цэсний хэсгүүд** | Зүүн цэсний 12 хэсэг (Хяналтын самбар, Байгууллага, эрсдэл, Үл нийцэл CAP, Хяналт шалгалт, Гэрчилгээ, Агаарын хөлөг, Эрсдэлд суурилсан төлөвлөлт, Дүрэм журам, Арга хэмжээ, Тайлан, Олон улс, Тохиргоо) |
| **Самбарын үзүүлэлтийн хайрцаг** | Самбар дээрх 6 тоон хайрцаг |
| **Самбарын хэсгүүд** | Самбарын блокууд (анхаарал шаардсан залруулалт, эрсдэлийн матриц, шалгалтын график, замын зураг, дүрмийн шинэчлэлт, USOAP) |
| **«Олон улс» хэсгийн самбарууд** | Тус хэсгийн 14 самбар — гарчиг, **тайлбар бичвэр**, дараалал, зочинд харуулах эсэх |

Мөр бүрт:

- **Зочинд харуулах** тэмдэглэгээ — унтраавал зочны цэс/самбараас бүрмөсөн алга болно.
- **Нэрийг** нь шууд бичиж засна.
- **↑ ↓** товчоор дарааллыг солино.

Өөрчлөлт **Харагдацыг хадгалах** дарсны дараа хүчинтэй («Өөрчлөлтийг болих»,
«Анхны байдалд буцаах» товчтой). Нэмэлтээр **Хяналтын самбар** дээр хэсэг
бүрийн толгойд **Нуух / Харуулах** товч байх бөгөөд тэр нь тэр дороо хадгалагдана.

Админ нэвтэрсэн үед бүх хэсэг үргэлж харагдана — зочинд хаасныг нь саарал
өнгөөр, тасархай хүрээтэйгээр ялгаж харуулна. Хэрэв бүх хэсгийг хаавал зочинд
«Энэ сангийн хэсгүүдийг түр хаасан байна» гэсэн мэдэгдэл гарах бөгөөд
нэвтрэх товч хэвээр үлдэнэ.

Энэ тохиргоо `settings` хүснэгтийн `main` мөрийн `dash` талбарт хадгалагдана —
бүх төхөөрөмж, бүх хэрэглэгчид нэг ижил харагдана. Сан холбогдоогүй, эсвэл
`dash` талбар байхгүй үед анхны байдал (бүх хэсэг нээлттэй) хэрэглэгдэнэ.

Гэрчилгээний **хүчинтэй хугацаа** орсон тул хяналтын самбарын «Гэрчилгээ»
хайрцаг дуусах хугацааг шууд сэрэмжлүүлнэ.

Эдгээр байгууллагын **эрсдэлийн үнэлгээ (нарийн төвөгтэй байдал, УТ-ны
төлөвшилт) хоосон** — эх сурвалжид байхгүй. EASA-гийн зөвлөмжөөр эдгээрийг
мэргэжилтнүүдийн зөвлөл консенсусаар тогтоох ёстой. Бөглөх хүртэл тухайн
байгууллага эрсдэлийн матрицад орохгүй.

> Бүртгэл шинэчлэгдэх тул үе үе mcaa.gov.mn-тэй тулгаж, «Засах» цонхноос
> гэрчилгээний хугацааг шинэчилнэ.

| Гадаад тээвэрлэгч (24) | Гэрчилгээ (аль хэдийн орсон) |

| НТЧ гэрчилгээ (40) | Гэрчилгээ — бүртгэлийн дугаараар агаарын хөлөгт холбогдоно |

### Агаарын хөлөг — шинэ хүснэгт

`aircraft` хүснэгт нэмэгдсэн (`schema.sql` дотор DDL нь бий): бүртгэлийн дугаар,
маяг, үйлдвэрлэгчийн дугаар, ангилал, бүртгэл (МУ/гадаад), бүртгэсэн огноо,

чадварын гэрчилгээг бүртгэлийн дугаараар нь автоматаар хослуулж, хугацаа

Эх файлын зөрүүг «Тайлан 2026-H1 → Өгөгдлийн зөрүү» хэсэгт жагсаасан.

| Найман чухал элемент (CE-1…CE-8) | Монгол Улс, ICVM-ийн тайлан, дэлхий ба APAC | хоёулаа |

### Монголын тоо баримт хаанаас ирдэг вэ

- **Тайлан 2026-H1** (`REPORT` объект, 0616.xlsx-аас) — USOAP AGA аудит, ICVM, CAP хугацаа
- **Хяналтын сан** (Supabase) — ИНД-129 гэрчилгээ, гадаадын сургалт/ТҮ байгууллага,
  гадаадад бүртгэлтэй агаарын хөлөг. Сан шинэчлэгдэх бүрт эдгээр тоо өөрчлөгдөнө.
  Сан холбогдоогүй үед тайлангийн тогтмол тоо руу шилжинэ.

> ⚠️ **Гадаадын тээвэрлэгчийн харьяа улсыг тээвэрлэгчийн нэрээр тогтоосон** —
> ИНД-129-ийн гэрчилгээний бүртгэлд улсын талбар байхгүй. Энэ бол ИНЕГ-ын эх
> сурвалжийн биш, энэ сангийн ангилал (`INTL_CARRIER_STATE`). Эрсдэлийн үнэлгээнд
> ашиглахын өмнө гэрчилгээний эх баримтаас баталгаажуулна. Мөн улсын EI нь тухайн
> улсын **нийт** хяналтын тогтолцооны үзүүлэлт — нэг тээвэрлэгчийн үнэлгээ биш.

### Яагаад прокси хэрэгтэй вэ

`istars.icao.int` нь cross-origin хүсэлтэд `Access-Control-Allow-Origin` толгой
өгдөггүй, мөн сайтын CSP нь `connect-src 'self'` тул **хөтчөөс шууд татах
боломжгүй** (шалгасан: `TypeError: Failed to fetch`). Тиймээс
`functions/api/intl.js` буюу **Cloudflare Pages Function** сервер талаас татаж,
цэгцэлж, ижил эх үүсвэрээр буцаана. Хариу ирмэг дээр хоног хадгалагдана.

Pages төсөлд `functions/` хавтас байхад Functions **автоматаар идэвхжинэ** —
нэмэлт тохиргоо шаардахгүй.

### Прокси ажиллахгүй бол

Хуудас `public/hyanalt/intl-snapshot.json` дахь **хадгалсан хуулбар** руу
автоматаар шилжиж, дээд талд «хадгалсан хуулбар» гэсэн шар тэмдэг гаргана.
Локал `node serve.js` дээр Functions ажиллахгүй тул үргэлж энэ горимоор харагдана.

### Анхаарах зүйл — «яагаад 2017 он гэж гарч байна вэ»

**Энэ бол алдаа биш.** ICAO-гийн өөрийн нээлттэй жагсаалтад Монгол Улс
өнөөдрийн байдлаар **2017** гэж бичигдсэн байна (icao.int-ийн USOAP interactive
viewer дээр шууд шалгаж болно). `EIlatest` нь улс бүрт **яг нэг мөр** буцаадаг —
улс бүрийн хамгийн сүүлийн үйл ажиллагаа. 2026.04.22 – 05.04-нд болсон USOAP CMA
аудитын үр дүн PQ-гийн статус ICAO-гийн төв байгууллагад баталгаажсаны дараа
нийтлэгддэг тул хэдэн сарын хоцролт үүсдэг. **ICAO шинэчилмэгц энэ хуудас
дараагийн ачаалалтаа өөрөө татна — гараар засах шаардлагагүй.**

«USOAP-ийн үйл ажиллагааны түүх» самбарт дөрвөн дүнг зэрэгцүүлж харуулна:

| Он | Үйл ажиллагаа | Үнэлгээ | Эх сурвалж |
|---|---|---|---|
| 2010 | USOAP CSA иж бүрэн аудит (06.28–07.07) | 87.92 | ICAO-гийн эцсийн тайлан, 2011.05 |
| 2017 | ICVM (08.29–09.04) | 89.55 | ICAO-гийн ICVM эцсийн тайлан, 2017.12 |
| **2026** | **USOAP CMA бүрэн хэмжээний аудит (04.22–05.04)** | **83.06** | **Тайлан 2026-H1** |
| — | ICAO-гийн нээлттэй санд тусгагдсан | 88.39 | ICAO iSTARS |

2010 ба 2017 оны үзүүлэлт нь **ИНЕГ-ын цахим хуудсанд байршуулсан ICAO-гийн албан ёсны
эцсийн тайлангаас**; 2026 оны үнэлгээ нь **«Тайлан 2026-H1»**-ээс.

> ⚠️ **2026 оны үнэлгээг 2017 оны үзүүлэлттэй шууд харьцуулах үндэслэлгүй.**
> USOAP CMA-гийн аргачлал, протокол асуулга **2024 онд бүрэн шинэчлэгдсэн** бөгөөд Монгол
> Улс шинэчилсэн аргачлалаар 2010 оноос хойш анх удаа хамрагдсан. Харьцуулах үндэслэл нь
> дэлхийн (70.90%) ба Ази, Номхон далайн бүсийн (69.63%) дундаж бөгөөд Монгол Улс хоёуланг нь
> **+12.16 / +13.43 нэгжээр** давсан. Энэ зөрүүг хуудас ICAO-гийн шууд өгөгдлөөс өөрөө тооцно.

«2026 оны аудитын хамрах хүрээ» самбарт **8 чиглэл, 835 протокол асуулгыг** жагсаасан:
LEG, ORG, AIG, OPS, AIR, PEL, AGA, ANS. Чиглэл тус бүрийн үзүүлэлт ICAO-гийн эцсийн
тайлангаар тодорхойлогдож, нээлттэй санд тусгагдмагц энэ хуудсанд автоматаар нэмэгдэнэ.
ИНЕГ 2026.05.06-ны [мэдээгээрээ](https://mcaa.gov.mn/news/post1) урьдчилсан үнэлгээг
74.96 хувь гэж мэдээлснийг самбарын тайлбарт тэмдэглэсэн.

ICVM-ийн тайлангийн 89.55 ба ICAO-гийн санд тусгагдсан 88.39-ийн 1.16 нэгжийн зөрүү нь
2017 оноос хойш протокол асуулгын статус шинэчлэгдсэнтэй холбоотой — хоёулаа зөв, өөр өөр
цаг үеийнх.

### Админ энэ хэсгийг хэрхэн засах вэ

Нэвтэрсэн админ «Олон улс» хэсгийн **бүх самбарыг** засварлана:

**Хурдан арга — хэсэг дээрээсээ.** Самбар бүрийн толгойд **Нуух / Харуулах** товч гарна.
Дарвал тэр дороо хадгалагдаж, зочны харагдац шууд өөрчлөгдөнө. Нуусан самбар админд
саарал өнгөөр, «Зочинд нуусан» тэмдэгтэй харагдсаар байна. Дээд талд хэдэн самбар
хаалттай байгааг мэдэгдэнэ.

**Дэлгэрэнгүй — Тохиргоо хэсгээс.** **Тохиргоо → Зочны харагдац → «Олон улс» хэсгийн
самбарууд** дотор мөр бүрт:

| Хяналт | Юу хийдэг |
|---|---|
| **Гарчиг** | Самбарын нэрийг шууд бичиж солино |
| **Тайлбар бичвэр** | Самбарын доорх тайлбарыг бүрэн эхээр нь засна (7 самбарт бий) |
| **Зочинд харуулах** | Тэмдэглэгээг авбал зочны хувьд тэр самбар бүрмөсөн харагдахгүй |
| **↑ ↓** | Самбарын дарааллыг солино |

Өөрчлөлт **Харагдацыг хадгалах** дарсны дараа хүчинтэй болно.

#### Тайлбар бичвэрийн бичиглэл

| Бичих нь | Үр дүн |
|---|---|
| хоосон мөр | догол мөр тусгаарлана |
| мөрийг `!` тэмдгээр эхлүүлэх | анхааруулгын (шар) өнгөтэй хайрцаг |
| `**үг**` | тод үсэг |
| `{ТҮЛХҮҮР}` | амьд утгаар солигдоно |

Боломжтой түлхүүрүүд (Тохиргоо хэсэгт бас жагсаана): `{ОН}` ICAO-д тусгагдсан он,
`{ICAO}` ICAO-гийн үзүүлэлт, `{АУДИТ_ОН}` сүүлийн аудитын он, `{АУДИТ}` түүний үнэлгээ,
`{ХУГАЦАА}` аудитын хугацаа, `{АСУУЛГА}` протокол асуулгын тоо, `{ЧИГЛЭЛ}` чиглэлийн тоо,
`{ДЭЛХИЙ}` дэлхийн дундаж, `{АЗИ}` APAC-ийн дундаж, `{ЭРЭМБЭ}` дэлхийн эрэмбэ,
`{УЛС}` нийт улсын тоо, `{ТАТСАН}` сүүлд шинэчилсэн огноо, `{CAP}` CAP байршуулах хоног.

Ингэснээр бичвэрийг чөлөөтэй засахад **тоонууд амьд хэвээр** үлдэнэ — ICAO-гоос шинэ
өгөгдөл ирэхэд гараар засах шаардлагагүй. Бичвэрийг бүхэлд нь устгавал тэр самбар
тайлбаргүйгээр гарна.

Тохиргоо нь бусад харагдацын адил `settings` хүснэгтийн `main` мөрийн `dash.intl`
талбарт хадгалагдана. Хадгалсан тохиргоонд байхгүй шинэ самбар нэмэгдвэл анхны
байрандаа, нээлттэй байдлаар автоматаар орж ирнэ.

### Бичвэрийн хэв маяг

Энэ хэсгийн бүх бичвэрийг **албан ёсны хэв маягаар** бичсэн: асуулт хэлбэрийн гарчиг,
тушаах өнгө аяс, «байхгүй / алга / тодорхойгүй» гэх мэт сөрөг томьёолол ашиглаагүй.

«эх баримтаар тодорхойлох» гэсэн урагшаа чиглэсэн томьёолол хэрэглэнэ.

### ЕХ-ны нисэхийн аюулгүй байдлын жагсаалт

Европын комисс зөвхөн **PDF** хэлбэрээр нийтэлдэг тул автоматаар уншуулах
боломжгүй. «Эх сурвалж» самбараас албан ёсны хуудас руу холбосон — ИНД-129-ийн

- **Шууд дамжуулалт (realtime) байхгүй.** Өөрчлөлт 60 секунд тутам,

  УТ-ны төлөвшилт) бөглөгдөөгүй.** EASA-гийн зөвлөмжөөр эдгээрийг
