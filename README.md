# ИНЕГ · Нисэхийн аюулгүй ажиллагааны хяналт

**Амьд хаяг: https://mrt-mn.pages.dev**
Cloudflare Pages, төсөл `mrt-mn`. `main` салбар руу push хийхэд автоматаар шинэчлэгдэнэ.

Хоёр вэб апп нэг сайтад:

| Хаяг | Апп | Өгөгдөл |
|---|---|---|
| `/` | Нүүр хуудас | — |
| `/hyanalt/` | **Хяналтын сан** — байгууллага, үл нийцэл (CAP), шалгалт, гэрчилгээ, эрсдэлд суурилсан төлөвлөлт, дүрмийн шинэчлэлт, арга хэмжээний явц | Supabase |
| `/garyn-avlaga/` | **Байцаагчийн гарын авлага** — 12 модуль, 48 карт, кэйс, 20 асуултын тест · **зөвхөн нэвтэрсэн админ** | Статик (явц нь браузерт) |

Бүтээх алхам шаардлагагүй — цэвэр HTML/CSS/JS. Гуравдагч сан ашиглаагүй.

```
public/                 ← нийтлэгдэх агуулга (build output directory)
  index.html
  hyanalt/{index.html, config.js, db.js}
  hyanalt/intl-snapshot.json  ← ICAO-гийн үзүүлэлтийн нөөц хуулбар
  garyn-avlaga/index.html
  assets/theme.css      ← гурван хуудсын нэгдсэн албан ёсны загвар
  assets/gate.js        ← гарын авлагын нэвтрэлтийн хаалт
  _headers              ← Cloudflare Pages-ийн аюулгүй байдлын толгойнууд
functions/api/intl.js   ← ICAO iSTARS прокси (Cloudflare Pages Function)
supabase/schema.sql     ← хүснэгт, эрхийн дүрэм, эх өгөгдөл
test/                   ← локал тест (нийтлэгдэхгүй)
serve.js                ← локал сервер (нийтлэгдэхгүй)
```

## 1. Supabase — өгөгдлийн сан

1. [supabase.com](https://supabase.com) дээр үнэгүй бүртгүүлж **шинэ төсөл** үүсгэнэ.
   Бүс нутгийг **Singapore** эсвэл **Tokyo** сонговол Монголоос хамгийн хурдан.
2. Зүүн цэснээс **SQL Editor** → **New query** → `supabase/schema.sql`-ын
   **бүх агуулгыг** хуулж тавиад **Run**.
   Энэ нь 9 хүснэгт, эрхийн дүрэм, 2026 оны I хагас жилийн эх өгөгдлийг үүсгэнэ.
   Дахин ажиллуулахад аюулгүй — давхардсан бичлэг үүсгэхгүй.
3. **Authentication → Users → Add user** дээр админ хэрэглэгч үүсгэнэ
   (и-мэйл + нууц үг). *Auto Confirm User* -ийг заавал асаана.
   Зөвхөн энэ хэрэглэгч өгөгдөл нэмэх, засах, устгах эрхтэй.
4. **Authentication → Providers → Email** хэсэгт
   **«Enable email signups»**-ийг **УНТРААНА**. Ингэснээр гаднаас хэн ч
   өөрөө бүртгүүлж бичих эрх авахгүй.
5. **Project Settings → API** хуудаснаас хоёр утгыг хуулна:
   - **Project URL** (`https://xxxx.supabase.co`)
   - **anon / publishable key** (`eyJ...` эхэлдэг урт түлхүүр)
6. `public/hyanalt/config.js` файлыг нээж тэр хоёр утгыг тавина.

> ⚠️ **`service_role` түлхүүрийг ХЭЗЭЭ Ч энд тавьж болохгүй.** Тэр нь эрхийн
> дүрмийг тойрдог. `anon` түлхүүр нь нийтэд ил байхаар зориулагдсан бөгөөд
> аюулгүй — хамгаалалтыг RLS дүрэм хангана (хүн бүр УНШИНА, зөвхөн
> нэвтэрсэн хэрэглэгч БИЧНЭ).

## 2. Cloudflare Pages — нийтлэх

**GitHub-аар (зөвлөж байна — дараа нь push хийхэд автоматаар шинэчлэгдэнэ):**

1. GitHub репозитор: **https://github.com/jagaajacky99/MNG** — үүсгэж, түлхсэн. ✅
2. Дахин холбох шаардлагатай бол (remote аль хэдийн тохируулагдсан):
   ```bash
   git remote add origin https://github.com/jagaajacky99/MNG.git
   git push -u origin main
   ```
3. [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** →
   **Create** → **Pages** → **Connect to Git** → репозитороо сонгоно.
4. Тохиргоо:
   - **Framework preset:** `None`
   - **Build command:** хоосон орхино
   - **Build output directory:** `public`
5. **Save and Deploy.** Төсөл `mrt-mn`, домайн `mrt-mn.pages.dev` — үүсгэсэн. ✅

**GitHub-гүйгээр (хурдан турших):** Pages → **Upload assets** дээр
`public` хавтасны агуулгыг чирж оруулна.

### Домайн нэр
Үнэгүй `*.pages.dev` дэд домайныг Pages төслийн нэрээр өөрчилнө
(Settings → General → Project name). Өөрийн домайнтай бол
Custom domains хэсгээс үнэгүй холбоно.

Нийтлэгдсэний дараа:

- `/hyanalt/` нээхэд баруун дээд буланд **«Зөвхөн харах»** гэж гарвал

  ажиллаагүй байна. Хөтчийн консолоос алдааг харна.

## 3.1. Зочны харагдацыг тохируулах

Зөвхөн нэвтэрсэн админд. **Тохиргоо → Зочны харагдац** хэсэгт гурван бүлэг жагсаалт:

| Бүлэг | Юу удирдах вэ |
|---|---|
| **Цэсний хэсгүүд** | Зүүн цэсний 12 хэсэг (Хяналтын самбар, Байгууллага, эрсдэл, Үл нийцэл CAP, Хяналт шалгалт, Гэрчилгээ, Агаарын хөлөг, Эрсдэлд суурилсан төлөвлөлт, Дүрэм журам, Арга хэмжээ, Тайлан, Олон улс, Тохиргоо) |
| **Самбарын үзүүлэлтийн хайрцаг** | Самбар дээрх 6 тоон хайрцаг |
| **Самбарын хэсгүүд** | Самбарын блокууд (анхаарал шаардсан залруулалт, эрсдэлийн матриц, шалгалтын график, замын зураг, дүрмийн шинэчлэлт, USOAP) |

Мөр бүрт:

- **Зочинд харуулах** тэмдэглэгээ — унтраавал зочны цэс/самбараас бүрмөсөн алга болно.
- **Нэрийг** нь шууд бичиж засна.
- **↑ ↓** товчоор дарааллыг солино.

Өөрчлөлт **Харагдацыг хадгалах** дарсны дараа хүчинтэй («Өөрчлөлтийг болих»,
«Анхны байдалд буцаах» товчтой). Нэмэлтээр **Хяналтын самбар** дээр хэсэг
бүрийн толгойд **Нуух / Харуулах** товч байх бөгөөд тэр нь тэр дороо хадгалагдана.

Админ нэвтэрсэн үед бүх хэсэг үргэлж харагдана — зочинд хаасныг нь саарал
өнгөөр, тасархай хүрээтэйгээр ялгаж харуулна. Хэрэв бүх хэсгийг хаавал зочинд
«Энэ сангийн хэсгүүдийг түр хаасан байна» гэсэн мэдэгдэл гарах бөгөөд
нэвтрэх товч хэвээр үлдэнэ.

Энэ тохиргоо `settings` хүснэгтийн `main` мөрийн `dash` талбарт хадгалагдана —
бүх төхөөрөмж, бүх хэрэглэгчид нэг ижил харагдана. Сан холбогдоогүй, эсвэл
`dash` талбар байхгүй үед анхны байдал (бүх хэсэг нээлттэй) хэрэглэгдэнэ.

мэргэжилтнүүдийн зөвлөл консенсусаар тогтоох ёстой. Бөглөх хүртэл тухайн
байгууллага эрсдэлийн матрицад орохгүй.

> Бүртгэл шинэчлэгдэх тул үе үе mcaa.gov.mn-тэй тулгаж, «Засах» цонхноос
> гэрчилгээний хугацааг шинэчилнэ.

## 3.4. «Олон улс» хэсэг — ICAO-гоос автоматаар татагдана

Зүүн цэсний **Олон улс** хэсгийн бүх тоо ICAO-гийн **USOAP CMA** нээлттэй сангаас
(iSTARS) автоматаар ирнэ — гараар шивэх зүйлгүй:

| Самбар | Агуулга | Эх сурвалж |
|---|---|---|
| Монгол Улсын байр суурь | EI, дэлхийн эрэмбэ, APAC ба дэлхийн дундаж | ICAO |
| **Олон улсын аудит — дотоод тайлан ба ICAO-гийн сан** | AGA аудит 83.06, ICVM 89.55%, CAP 45 хоног — ICAO-гийн 88.39%-тай зэрэгцүүлсэн | **хоёулаа** |
| Найман чухал элемент (CE-1…CE-8) | Монгол vs дотоод тайлан vs дэлхий vs APAC | хоёулаа |
| Аудитын найман чиглэл | LEG, ORG, PEL, OPS, AIR, AIG, ANS, AGA | ICAO |
| Чиг хандлага | 2005–2026 оны график (SVG, гуравдагч сангүй) | ICAO |
| Бүс нутгийн харьцуулалт | ICAO-гийн 8 бүс | ICAO |
| Хөрш ба түнш орнууд | ИНД-129-ийн гадаад тээвэрлэгчийн харьяа улсууд орсон | ICAO |
| **Гадаадын оролцоо Монголын нисэхэд** | ИНД-129: 24, гадаад ТҮ 11, гадаад сургалт 18, гадаадад бүртгэлтэй АХ 6, хөрвүүлсэн үнэмлэх 31 | **сан / тайлан** |
| **Гадаадын тээвэрлэгч — харьяа улсын хяналтын чадавх** | 24 тээвэрлэгч бүрийг харьяа улсынх нь USOAP EI-тэй холбож, **эрсдэл өндөртэйг нь дээр** эрэмбэлсэн | **хоёулаа** |
| **Гадаадад бүртгэлтэй агаарын хөлөг** | 6 хөлөг, бүртгэсэн улсаар | **сан** |
| SSC | Ноцтой аюулгүй байдлын асуудал тогтоогдсон улсууд; ИНД-129-ийн тээвэрлэгчид SSC-тэй улсынх байвал сэрэмжлүүлнэ | хоёулаа |

### Монголын тоо баримт хаанаас ирдэг вэ

- **Тайлан 2026-H1** (`REPORT` объект, 0616.xlsx-аас) — USOAP AGA аудит, ICVM, CAP хугацаа
- **Хяналтын сан** (Supabase) — ИНД-129 гэрчилгээ, гадаадын сургалт/ТҮ байгууллага,
  гадаадад бүртгэлтэй агаарын хөлөг. Сан шинэчлэгдэх бүрт эдгээр тоо өөрчлөгдөнө.
  Сан холбогдоогүй үед тайлангийн тогтмол тоо руу шилжинэ.

> ⚠️ **Гадаадын тээвэрлэгчийн харьяа улсыг тээвэрлэгчийн нэрээр тогтоосон** —
> ИНД-129-ийн гэрчилгээний бүртгэлд улсын талбар байхгүй. Энэ бол ИНЕГ-ын эх
> сурвалжийн биш, энэ сангийн ангилал (`INTL_CARRIER_STATE`). Эрсдэлийн үнэлгээнд
> ашиглахын өмнө гэрчилгээний эх баримтаас баталгаажуулна. Мөн улсын EI нь тухайн
> улсын **нийт** хяналтын тогтолцооны үзүүлэлт — нэг тээвэрлэгчийн үнэлгээ биш.

### Яагаад прокси хэрэгтэй вэ

`istars.icao.int` нь cross-origin хүсэлтэд `Access-Control-Allow-Origin` толгой
өгдөггүй, мөн сайтын CSP нь `connect-src 'self'` тул **хөтчөөс шууд татах
боломжгүй** (шалгасан: `TypeError: Failed to fetch`). Тиймээс
`functions/api/intl.js` буюу **Cloudflare Pages Function** сервер талаас татаж,
цэгцэлж, ижил эх үүсвэрээр буцаана. Хариу ирмэг дээр хоног хадгалагдана.

Pages төсөлд `functions/` хавтас байхад Functions **автоматаар идэвхжинэ** —
нэмэлт тохиргоо шаардахгүй.

### Прокси ажиллахгүй бол

Хуудас `public/hyanalt/intl-snapshot.json` дахь **хадгалсан хуулбар** руу
автоматаар шилжиж, дээд талд «хадгалсан хуулбар» гэсэн шар тэмдэг гаргана.
Локал `node serve.js` дээр Functions ажиллахгүй тул үргэлж энэ горимоор харагдана.

### Анхаарах зүйл — «яагаад 2017 он гэж гарч байна вэ»

**Энэ бол алдаа биш.** ICAO-гийн өөрийн нээлттэй жагсаалтад Монгол Улс
өнөөдрийн байдлаар **2017** гэж бичигдсэн байна (icao.int-ийн USOAP interactive
viewer дээр шууд шалгаж болно). `EIlatest` нь улс бүрт **яг нэг мөр** буцаадаг —
улс бүрийн хамгийн сүүлийн үйл ажиллагаа. 2026.04.22 – 05.04-нд болсон USOAP CMA
аудитын үр дүн PQ-гийн статус ICAO-гийн төв байгууллагад баталгаажсаны дараа
нийтлэгддэг тул хэдэн сарын хоцролт үүсдэг. **ICAO шинэчилмэгц энэ хуудас
дараагийн ачаалалтаа өөрөө татна — гараар засах шаардлагагүй.**

«USOAP-ийн үйл ажиллагааны түүх» самбарт дөрвөн дүнг зэрэгцүүлж харуулна:

| Он | Үйл ажиллагаа | EI | Эх сурвалж |
|---|---|---|---|
| 2010 | USOAP CSA иж бүрэн аудит (06.28–07.07) | 87.92% | ICAO эцсийн тайлан, 2011.05 |

Бүх тоо нь **ИНЕГ-ын өөрийн цахим хуудсанд нийтэлсэн эх сурвалжаас** (2010, 2017 нь
ICAO-гийн албан ёсны эцсийн тайлан; 2026 нь ИНЕГ-ын мэдээ).

> ⚠️ **74.96% ба 88.39%-ийг хооронд нь харьцуулж болохгүй.** USOAP-CMA-гийн аргачлал,
> протокол асуулгууд **2024 онд бүрэн шинэчлэгдсэн** бөгөөд Монгол Улс 2010 оноос хойш
> 16 жилийн дараа шинэчилсэн аргачлалаар анх удаа шалгуулсан. Өөр шугамаар хэмжсэн дүн —
> бууралт биш. Зөв харьцуулах суурь нь дэлхийн (70.90%) ба APAC (69.63%) дундаж бөгөөд
> Монгол Улс хоёуланг нь **+4.06 / +5.33 нэгжээр** давсан. Энэ зөрүүг хуудас ICAO-гийн
> шууд өгөгдлөөс өөрөө тооцож харуулна.

«2026 оны аудитын хамрах хүрээ» самбарт **8 чиглэл, 835 протокол асуулгыг** жагсаасан:
LEG, ORG, AIG, OPS, AIR, PEL, AGA, ANS. ИНЕГ чиглэл тус бүрийн оноог нийтлээгүй —
зөвхөн AGA-гийн 153 PQ / 83.06 оноо нь дотоод тайлангаас мэдэгдэж байна. ICAO эцсийн
тайлангаа гаргаж, нээлттэй сандаа оруулмагц чиглэл тус бүрийн EI автоматаар гарч ирнэ.

ICVM-ийн тайлангийн 89.55% ба ICAO-гийн сан дахь 88.39%-ийн 1.16 нэгжийн зөрүү нь
2017 оноос хойш PQ-гийн статус шинэчлэгдсэнээс үүссэн — хоёулаа зөв, өөр өөр цаг үеийнх.

## Анхаарах зүйл

- **Шууд дамжуулалт (realtime) байхгүй.** Өөрчлөлт 60 секунд тутам,
  хуудас руу буцаж ирэхэд, мөн бичилт бүрийн дараа шинэчлэгдэнэ.
  Толгой дээрх **↻ Шинэчлэх** товчоор гараар татаж болно.
- **Шалгалт (517) ба гэрчилгээ (1 041)-ний мөр тутмын бүртгэл дутуу.**
  Эх тайлан зөвхөн нэгтгэсэн тоо өгсөн тул эдгээрийг ажилтнууд
  гар аргаар бүртгэнэ. Нэгтгэлийг «Тайлан 2026-H1» хэсгээс харна.
- **Байгууллагын эрсдэлийн үнэлгээ (нарийн төвөгтэй байдал,
  УТ-ны төлөвшилт) бөглөгдөөгүй.** EASA-гийн зөвлөмжөөр эдгээрийг
  нэг байцаагч биш, мэргэжилтнүүдийн зөвлөл консенсусаар тогтооно.
  Бөглөмөгц эрсдэлийн матриц, түвшин, жилийн давтамж шууд ажиллана.

- **Гарын авлагын хаалт нь хөтч талынх.** Нэвтрээгүй хүнд агуулга
  харагдахгүй, гэхдээ техник мэдлэгтэй хүн хуудсын эх кодоос гаргаж авах
  боломжтой хэвээр. Жинхэнэ сервер талын хаалт хэрэгтэй бол Cloudflare
  Access (Zero Trust) нэмнэ — үнэгүй, 50 хүртэл хэрэглэгч.
